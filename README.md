# Smart Reflow Plate Controller (ESP8266 & ESP32 Universal)

Универсальный контроллер нагревательного столика для пайки SMD / оплавления припоя по стандарту JEDEC.
Поддерживает сборку под **ESP8266 NodeMCU** и **ESP32 DevKit**.

---

##  Основные возможности:
- **Безопасное управление 220V:** Медленный ШИМ (1 сек) для твердотельных реле (SSR). Тройная защита: от обрыва термопары, перегрева и пожарный сторож `F_NO_RISE`.
- **Авто-профили пайки JEDEC:** Полноценный 4-стадийный термопрофиль (*Preheat -> Soak -> Reflow -> Cooldown*).
- **Хранение профилей в LittleFS (`/profiles.json`):** Редактирование времени и температур любого профиля прямо из браузера.
- **Web-интерфейс (GZIP):** Сжатый HTML5 интерфейс с живым графиком температуры на Canvas (работает офлайн).
- **Интеграция в Умный Дом:** Отправка всей телеметрии по протоколу **MQTT** (Home Assistant).
- **OTA-прошивка:** Обновление прошивки по воздуху с индикатором процентов прогресса прямо из браузера.
- **Энергоучет и статистика:** Подсчет потребленной энергии (Wh), счетчик циклов пайки и учет общего времени работы ТЭНа (моточасы).
- **Аппаратное расширение:** Поддержка I2C-расширителя **PCF8574** (авто-обдув кулером и физические кнопки `Back` / `Confirm`).
- **Защита OLED от выгорания:** Автоматическое гашение экрана через 15 минут бездействия.

## 🔌 Hardware Pinout (Аппаратные подключения)

### Вариант 1: ESP32 DevKit (Прямое подключение, БЕЗ PCF8574)
> Для сборки с окружением `[env:esp32dev]`. Все модули и кнопки подключаются напрямую к выводам микроконтроллера.

| Периферия | Пин ESP32 | GPIO | Тип | Примечание / Обвязка |
| :--- | :---: | :---: | :---: | :--- |
| **SSR Реле (220V)** | **GPIO 25** | 25 | Out | Затвор 2N7002 через 220 Ом (стяжка 10к к GND) |
| **Кулер (Fan)** | **GPIO 27** | 27 | Out | Затвор N-Ch MOSFET (AO3400) через 100 Ом, защитный диод |
| **Кнопка BACK** | **GPIO 32** | 32 | In | Кнопка замыкает пин на GND (Pull-Up внутри) |
| **Кнопка CONFIRM** | **GPIO 33** | 33 | In | Кнопка замыкает пин на GND (Pull-Up внутри) |
| **Зуммер (Buzzer)** | **GPIO 26** | 26 | Out | Плюс зуммера через 100 Ом, минус на GND |
| **MAX6675 SO** | **GPIO 16** | 16 | In | SPI MISO термопары |
| **MAX6675 CS** | **GPIO 4** | 4 | Out | SPI Chip Select термопары |
| **MAX6675 SCK** | **GPIO 17** | 17 | Out | SPI Clock термопары |
| **Энкодер CLK** | **GPIO 18** | 18 | In | Прерывание вращения (Канал A) |
| **Энкодер DT** | **GPIO 19** | 19 | In | Определение направления (Канал B) |
| **Энкодер SW** | **GPIO 23** | 23 | In | Кнопка энкодера (Старт/Стоп нагрева) |
| **OLED SDA** | **GPIO 21** | 21 | I2C | Линия данных дисплея SSD1306 (100 кГц) |
| **OLED SCL** | **GPIO 22** | 22 | I2C | Тактовая линия дисплея SSD1306 (100 кГц) |
| **NTC 100K (Опция)**| **VP / GPIO 36**| 36 | ADC | Делитель с подтяжкой 4.7к к 3.3V (12 бит) |

### 🎛 Лицевая комбо-панель (Экран + Энкодер + Кнопки)
Распиновка 9-контактной гребёнки с лицевой стороны слева направо:
`[confirm] [oled_sda] [oled_scl] [enc_push] [enc_tpa] [enc_tpb] [bak] [gnd] [3v3-5v]`

Куда паять шлейф панели в зависимости от выбранного микроконтроллера:

```text
┌──────────────────┬──────────────────────┬──────────────────────┐
│ Пин панели       │ Подключение к ESP32  │ Подключение к ESP8266│
├──────────────────┼──────────────────────┼──────────────────────┤
│ confirm          │ GPIO 33              │ P3 (на PCF8574)      │
│ oled_sda         │ GPIO 21 (SDA)        │ D2 (GPIO4, SDA)      │
│ oled_scl         │ GPIO 22 (SCL)        │ D1 (GPIO5, SCL)      │
│ enc_push         │ GPIO 23              │ D7 (GPIO13)          │
│ enc_tpa          │ GPIO 18              │ D5 (GPIO14)          │
│ enc_tpb          │ GPIO 19              │ D6 (GPIO12)          │
│ bak              │ GPIO 32              │ P2 (на PCF8574)      │
│ gnd              │ GND                  │ GND                  │
│ 3v3-5v           │ 3.3V                 │ 3.3V                 │
└──────────────────┴──────────────────────┴──────────────────────┘
```text

##  Сборка и прошивка (PlatformIO)
Проект настроен для сборки в среде **VS Code + PlatformIO**:
1. Клонируйте репозиторий.
2. Откройте папку проекта в VS Code.
3. Нажмите **Build** (скрипт `version_bump.py` сам сожмет веб-морду в GZ и посчитает номер билда).
4. Прошейте плату по кабелю или загрузите `firmware.bin` через Web OTA.
