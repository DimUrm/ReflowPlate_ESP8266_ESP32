# Smart Reflow Plate Controller (ESP8266 & ESP32 Universal)

Универсальный двухплатформенный контроллер нагревательного столика для пайки SMD / оплавления паяльных паст по стандарту JEDEC.  
Поддерживает сборку под **ESP8266 NodeMCU v2** и **ESP32 DevKit**.

---

## Основные возможности

- **Безопасное управление 220V:** Медленный ШИМ (окно 1 сек) для твердотельных реле (SSR). Четырехуровневая защита: аварийный сброс при OTA, сторож отсутствия нагрева `F_NO_RISE`, отключение по перегреву и аппаратный сброс пина реле в `LOW` при любых сбоях.
- **Три варианта экранов на выбор (через `#define` в `config.h`):**
  - **Цветной IPS 1.14" ST7789 (240x135)** — аппаратный SPI, цветная шкала мощности и градиент нагрева (ESP32).
  - **Ретро LCD Nokia 5110 PCD8544 (84x48)** — SPI, ультра-контрастный монохромный экран с крупными цифрами (ESP32).
  - **Монохромный OLED 0.96"/1.3" SSD1306/SH1106 (128x64)** — I2C, с полным многостраничным меню (ESP8266 и ESP32).
  *(Дисплеи ST7789 и Nokia 5110 используют одни и те же пины SPI — их можно менять без перепайки платы!)*
- **Интерактивное многостраничное меню (на OLED):** 
  - Вход удержанием энкодера (1 сек).
  - Листание и выбор профилей, настройка звука, Standby-таймера, обдува и калибровки PID (Auto-Tune).
  - 4-страничный диагностический экран `INFO`: версия прошивки, параметры сети Wi-Fi/IP/RSSI, аптайм, свободный Heap и энергоучет ТЭНа.
- **Авто-профили пайки JEDEC:** Полноценный 4-стадийный термопрофиль (*Preheat -> Soak -> Reflow -> Cooldown*) с защитным таймаутом выхода на пик (90 сек).
- **Web-интерфейс (GZIP в PROGMEM):** Автономный HTML5 веб-интерфейс с живым графиком температуры на Canvas (работает без интернета).
- **Интеграция с Home Assistant:** Полная телеметрия по протоколу **MQTT** с защитой от зависания цикла пайки.
- **Надежная Web OTA-прошивка:** Обновление бинарником прямо из браузера со шкалой прогресса и автоматическим выключением нагревателя.
- **Энергоучет и статистика:** Подсчет потребленной энергии в Ватт-часах (Wh), счетчик циклов пайки и учет моточасов ТЭНа с сохранением в LittleFS.

## Hardware Pinout (Аппаратные подключения)

### Вариант 1: ESP32 DevKit (Прямое подключение)
> Сборка: `[env:esp32dev]`. Все модули, кнопки и мосфет кулера подключаются напрямую к GPIO платы (расширитель PCF8574 не требуется).

| Периферия | Пин ESP32 | GPIO | Тип | Примечание / Обвязка |
| :--- | :---: | :---: | :---: | :--- |
| **SSR Реле (220V)** | **GPIO 25** | 25 | Out | Вход реле (обязателен стягивающий резистор 10к к GND!) |
| **Кулер обдува (Fan)** | **GPIO 27** | 27 | Out | Затвор N-Ch MOSFET (AO3400/IRLML2502) через 100 Ом, защитный диод |
| **Кнопка BACK** | **GPIO 32** | 32 | In | Замыкает пин на GND (внутренняя подтяжка `INPUT_PULLUP`) |
| **Кнопка CONFIRM** | **GPIO 33** | 33 | In | Замыкает пин на GND (внутренняя подтяжка `INPUT_PULLUP`) |
| **Зуммер (Buzzer)** | **GPIO 26** | 26 | Out | Сигнал ШИМ (LEDC канал 0). Плюс через 100 Ом, минус к GND |
| **MAX6675 SO** | **GPIO 16** | 16 | In | SPI MISO термопары K-типа |
| **MAX6675 CS** | **GPIO 4** | 4 | Out | SPI Chip Select термопары |
| **MAX6675 SCK** | **GPIO 17** | 17 | Out | SPI Clock термопары |
| **Энкодер CLK** | **GPIO 18** | 18 | In | Прерывание вращения (Канал A) |
| **Энкодер DT** | **GPIO 19** | 19 | In | Определение направления (Канал B) |
| **Энкодер SW** | **GPIO 23** | 23 | In | Кнопка энкодера (Клик = Старт/Стоп, Удержание 1 сек = Меню) |
| **SPI SCLK (TFT / Nokia)**| **GPIO 14** | 14 | SPI | Тактовая линия дисплея: SCLK (ST7789) / CLK (Nokia 5110) |
| **SPI MOSI (TFT / Nokia)**| **GPIO 13** | 13 | SPI | Данные дисплея: MOSI (ST7789) / DIN (Nokia 5110) |
| **SPI CS (TFT / Nokia)**  | **GPIO 5**  | 5  | Out | Chip Select: CS (ST7789) / CE (Nokia 5110) |
| **SPI DC (TFT / Nokia)**  | **GPIO 21** | 21 | Out | Data / Command дисплея |
| **SPI RST (TFT / Nokia)** | **GPIO 22** | 22 | Out | Reset дисплея |
| **Подсветка (BL / LIGHT)**| **3.3V**    | —  | Power| Строго 3.3V! (Для Nokia 5110 подсветку можно через 100-220 Ом) |
| **NTC 100K (Опция)**| **GPIO 36 (VP)**| 36 | ADC | Строго группа ADC1! Делитель с резистором 4.7к к 3.3V |

*(Примечание: Если на ESP32 используется монохромный OLED SSD1306, в `config.h` включается `#define DISPLAY_SSD1306`, а пины GPIO 21 и GPIO 22 переходят в режим I2C SDA/SCL).*

### Вариант 2: NodeMCU v2 (ESP8266 + Расширитель I2C PCF8574)
> Сборка: `[env:nodemcuv2]`. Недостающие пины вынесены на I2C-расширитель PCF8574 (адрес 0x20). Экран — OLED SSD1306.

| Периферия | Пин NodeMCU | GPIO / Порт | Примечание / Обвязка |
| :--- | :---: | :---: | :--- |
| **SSR Реле (220V)** | **D8** | GPIO15 | Вход SSR через резистор (стяжка 10к к GND) |
| **Зуммер (Buzzer)** | **RX** | GPIO3 | Плюс зуммера через 100 Ом (генератор `tone()`) |
| **MAX6675 SO** | **D3** | GPIO0 | SPI MISO термопары (подтяжка 10к к 3.3V) |
| **MAX6675 CS** | **D4** | GPIO2 | SPI Chip Select термопары |
| **MAX6675 SCK** | **D0** | GPIO16 | SPI Clock термопары |
| **Энкодер CLK** | **D5** | GPIO14 | Прерывание вращения (Канал A) |
| **Энкодер DT** | **D6** | GPIO12 | Определение направления (Канал B) |
| **Энкодер SW** | **D7** | GPIO13 | Кнопка энкодера |
| **I2C SDA** | **D2** | GPIO4 | Общая шина данных: OLED SSD1306 + PCF8574 |
| **I2C SCL** | **D1** | GPIO5 | Общая тактовая шина: OLED SSD1306 + PCF8574 |
| **NTC 100K (Опция)**| **A0** | ADC0 | Делитель с подтяжкой 4.7к к 3.3V (10 бит) |
| **Кулер (Fan)** | — | **P0 (PCF8574)** | Затвор N-Ch MOSFET (AO3400) через 100 Ом |
| **Кнопка BACK** | — | **P2 (PCF8574)** | Кнопка замыкает вывод P2 на GND |
| **Кнопка CONFIRM** | — | **P3 (PCF8574)** | Кнопка замыкает вывод P3 на GND |

## Сборка и прошивка (PlatformIO)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/DimUrm/ReflowPlate_ESP8266_ESP32.git
Откройте папку проекта в VS Code.
В файле src/config.h выберите нужный экран (раскомментируйте один из трех вариантов):
code
C++
#define DISPLAY_ST7789       // Цветной IPS ST7789
//#define DISPLAY_NOKIA5110  // Ретро LCD Nokia 5110
//#define DISPLAY_SSD1306    // Монохромный OLED 128x64
Выберите целевое окружение в нижней статусной строке:
env:esp32dev — для ESP32 (автоматически применит разметку min_spiffs.csv под OTA).
env:nodemcuv2 — для ESP8266.
Нажмите Build (галочка) или прошейте плату через USB-кабель.
