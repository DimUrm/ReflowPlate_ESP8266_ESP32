# Smart Reflow Plate Controller (ESP8266 & ESP32 Universal)

Профессиональный контроллер нагревательного столика для пайки SMD-компонентов по термопрофилям JEDEC и нижнего ремонтного подогрева плат и смартфонов.  
Полностью кроссплатформенный проект: компилируется под **ESP8266 NodeMCU v2** и **ESP32 DevKit**.

---

## 🌟 Ключевые возможности

### 1. Нагрев и безопасность промышленного уровня
- **Медленный ШИМ (Zero-Cross):** 1-секундное окно коммутации для реле SSR-25DA (минимальные помехи в сеть 220V).
- **5 уровней аппаратной и программной защиты:**
  - Аппаратный термопредохранитель 250°C в силовой цепи 220V (защита от пробоя симистора).
  - Аварийное гарантированное отключение пина SSR в `LOW` при OTA-прошивке и перезагрузке.
  - Пожарный сторож отсутствия роста температуры `F_NO_RISE` (защита от отвалившейся термопары).
  - Контроль перегрева `F_OVERTEMP` и обрыва датчика.
  - Стягивающий резистор 10к на пине SSR (исключает бросок ТЭНа при старте чипа).

### 2. Продвинутые режимы работы
- **JEDEC Оплавление (Reflow):** 4-стадийный термопрофиль (*Preheat -> Soak -> Reflow -> Cooldown*).
- **Pre-Reflow Alert:** Звуковой предупреждающий отсчет за 5 секунд до начала плавления пасты.
- **Интеллектуальный обдув кулером (JEDEC Cooling Rate):** 3-ступенчатый безопасный ШИМ (35% -> 65% -> 100%) предотвращает растрескивание керамических SMD-конденсаторов (MLCC).
- **Режим ремонтного подогревателя (Preheater Mode):**
  - **Phone 80C (15 мин):** Безопасный прогрев и расклейка дисплейных модулей смартфонов.
  - **PCB 110C (20 мин):** Нижний подогрев массивных плат для легкой пайки феном.
  - Автоматическое отключение и звуковой сигнал по окончании таймера.

### 3. Три дисплея на выбор (смена через `#define` в `config.h`)
- **Цветной IPS 1.14" ST7789 (240x135):** Живой 90-секундный мини-график кривой пайки, цветная шкала мощности и градиент нагрева.
- **Ретро LCD Nokia 5110 PCD8544 (84x48):** Монохромный высококонтрастный экран с крупной индикацией на тех же пинах SPI!
- **Монохромный OLED SSD1306/SH1106 (128x64):** I2C-экран с интерактивным многостраничным меню энкодера.

### 4. Сетевые функции
- **Web-интерфейс в PROGMEM (GZIP):** Автономный HTML5 холст с графиком в реальном времени (без внешнего интернета).
- **MQTT / Home Assistant:** Полная телеметрия для домашней автоматизации (вытяжка, алерты).
- **Web OTA:** Беспроводная прошивка из браузера с разметкой `min_spiffs.csv` (1.9 МБ под код).

## 📌 Распиновка (Hardware Pinout)

### Вариант 1: ESP32 DevKit (Прямое подключение)
> Сборка: `[env:esp32dev]`. Расширитель PCF8574 не требуется.

| Периферия | Пин платы | GPIO | Тип | Примечание / Обвязка |
| :--- | :---: | :---: | :---: | :--- |
| **SSR Реле (220V)** | **GPIO 25** | 25 | Out | Вход реле (ОБЯЗАТЕЛЕН резистор 10к к GND!) |
| **Кулер обдува (Fan)** | **GPIO 27** | 27 | PWM | Аппаратный ШИМ (5 кГц). Затвор AO3400 через 100 Ом |
| **Кнопка BACK** | **GPIO 32** | 32 | In | Кнопка на GND (`INPUT_PULLUP`) |
| **Кнопка CONFIRM** | **GPIO 33** | 33 | In | Кнопка на GND (`INPUT_PULLUP`). Перебор 6 пресетов |
| **Зуммер (Buzzer)** | **GPIO 26** | 26 | Out | ШИМ LEDC канал 0. Плюс через 100 Ом, минус к GND |
| **MAX6675 SO** | **GPIO 16** | 16 | In | SPI MISO термопары K-типа |
| **MAX6675 CS** | **GPIO 4** | 4 | Out | SPI Chip Select термопары |
| **MAX6675 SCK** | **GPIO 17** | 17 | Out | SPI Clock термопары |
| **Энкодер CLK** | **GPIO 18** | 18 | In | Прерывание вращения (Канал A) |
| **Энкодер DT** | **GPIO 19** | 19 | In | Определение направления (Канал B) |
| **Энкодер SW** | **GPIO 23** | 23 | In | Кнопка энкодера (Клик = Старт/Стоп, Удержание = Меню) |
| **SPI SCLK (TFT/Nokia)** | **GPIO 14** | 14 | SPI | Тактовая линия дисплея (SCLK / CLK) |
| **SPI MOSI (TFT/Nokia)** | **GPIO 13** | 13 | SPI | Данные дисплея (MOSI / DIN) |
| **SPI CS (TFT/Nokia)** | **GPIO 5** | 5 | Out | Chip Select дисплея (CS / CE) |
| **SPI DC (TFT/Nokia)** | **GPIO 21** | 21 | Out | Data / Command дисплея |
| **SPI RST (TFT/Nokia)** | **GPIO 22** | 22 | Out | Reset дисплея |
| **Подсветка (BL)** | **3.3V** | — | Power| Питание подсветки (СТРОГО 3.3V!) |
| **NTC 100K (Опция)** | **GPIO 36 (VP)**| 36 | ADC | Строго ADC1! Делитель 4.7к к 3.3V (12 бит, 0..4095) |

## 🚀 Сборка проекта (PlatformIO)

1. Откройте проект в VS Code с установленным расширением PlatformIO.
2. В файле `src/config.h` выберите нужный экран (раскомментируйте один из трех):
   ```cpp
   #define DISPLAY_ST7789       // Цветной IPS ST7789
   //#define DISPLAY_NOKIA5110  // Ретро LCD Nokia 5110
   //#define DISPLAY_SSD1306    // Монохромный OLED
Выберите нужное окружение (env:esp32dev или env:nodemcuv2) и нажмите Build (✓).
Прошейте контроллер кабелем через порт USB.
